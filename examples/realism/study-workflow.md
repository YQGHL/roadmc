# RoadMC 可复现真实性研究工作流

本流程把公开数据核查、训练内部模型选择、冻结后的形态对照和合成机制诊断放在同一入口。它不自动更换生产默认，也不把程序运行成功解释为真实道路验收。

## 数据与结论的边界

截至2026-10-15，Royal Society 的四类沥青纹理矩阵可用于归一化形态、频谱和相关分析。论文提供0.5 mm的XY间距；CSV的Z单位和处理链仍待确认。原清单有20个TRAIN、100个已分析TEST，另8个TEST早期探索文件被排除。文件不是独立道路，现有TEST不能重新称为未见留出。

Rui Fan dataset3的三个视图用于局部参考面下的原生单位坑缘与深度形态对照。它们可能来自同一坑槽，不能报告毫米、材料损失体积或独立道路泛化。Def图像的1 mm/pixel是用户提供的XY工作假设；灰度不是已标定高程，阈值候选不是专家标注。

实验室SUR虽然能够解析单位，零码及处理映射仍未核实；现场TXT的原始单位和第四列意义待核实。MLS用于较粗几何和采样诊断，OSF用于原生坐标导入核查。水泥数据须独立准入，不能套用沥青分布。数据和实验产物均存放仓库外。

## 准备输入

使用[清单模板](study-manifest.template.json)填写实际文件路径及其SHA-256。模板中的替换项不能直接运行。相对路径以清单所在目录为基准；输入文件只读。PowerShell可用 `Get-FileHash -Algorithm SHA256 -LiteralPath '文件路径'` 获取哈希。

- `datasets`：逐来源声明 `source_id`、材料、XY/Z单位及核验证据、分组身份、数据用途、已有暴露和允许指标。
- `assets`：逐文件提供 `path`、`sha256`、绑定的 `source_id`。缺失、变更或未绑定的数据会被拒绝。
- 纹理阶段需要 `texture_archive`、`texture_split`、`texture_prior`，均绑定允许训练拟合的沥青来源，且允许归一PSD/ACF/W1。
- 原生坑槽阶段需要 `pothole_frame_01/02/03` 和 `pothole_label_01/02/03`。六个文件必须对应同一数据根目录的 `ptcloud/NN.mat` 与 `label/NN.png`，防止隐式读取清单外文件。
- `independent_holdout` 要求未暴露、已核验的道路/试件分组及材料；同组不能同时拟合和独立验收。单位不明时拒绝相应物理量，但保留允许的归一诊断。

准备[协议](study-protocol.json)后运行：

```powershell
$env:ROADMC_GENERATOR_NO_TORCH = '1'
python -m roadmc.scripts.run_realism_study `
  --manifest path/to/verified-manifest.json `
  --protocol examples/realism/study-protocol.json `
  --output-dir path/to/new-study
```

`--stages admission`只检查清单；`texture_fit texture_benchmark`执行纹理流程；`geometry_material pothole_native`执行病害机制与原生单位诊断。阶段默认超时1800秒，可显式调整。并行运行不同阶段时使用不同输出目录，避免共享账本被同时改写。

## 纹理选择与冻结

每类的五个原TRAIN文件做逐文件留一内部交叉验证。每折仅用其余四个文件估计目标矩和统计谱包络。历史基线的H/频带曾由全部五个TRAIN文件选择，因此这不是完整嵌套验证，也不是道路级泛化评估。

每类每折比较20个候选：一个旧非高斯方法、一个统计谱高斯方法、九个统计谱非高斯方法和九个迭代幅值匹配方法。后两组的偏度系数及超额峰度系数各取0.75、1、1.25；五个种子固定为0—4。这里的搜索点、迭代50次和容差1e-5都是数值设置，不是自然分布的实测范围。

统计谱从去平面、RMS归一且尚未分析低通的训练场提取，避免把分析滤波重复拟合进生成过程；目标矩和评分则使用同一分析预处理：去平面、400—500 cycles/m余弦过渡低通、RMS归一。主要指标是径向Hann加窗PSD的TV、ACF RMSE和标准化高度W1。

保留Pareto候选。只有三个主要指标的平均内部CV误差均不劣于旧基线的候选，才按归一误差均值选择；数值容差为1e-12，无合格候选则保留基线。最终配置用全部TRAIN重拟合并冻结，所有基准候选生成完之后才读取TEST。TEST只比较冻结的旧方法、三种中心设置和选中配置，不据结果继续调参。

## 坑缘、材料与观测

可选径向谐波作用于归一椭圆坐标。设

`g(theta) = (1 + sum[a_n*cos(n*theta)+b_n*sin(n*theta)]) / sqrt(1 + 0.5*sum[a_n^2+b_n^2])`，n=3、4、5。

要求各阶系数对的模长之和小于1，以保证正半径；分母使连续面积保持πab。足迹、碗形损失与材料更新共享 `u/g, v/g`。它是有定性动机的D类模型假设，只能表示相对中心星形的边界，不能表示任意凹陷、悬垂或多层坑壁。没有系数或系数全零时保持旧结果。

机制实验使用同一人工基底、相同事件位置、名义尺度及种子；先比较旧椭圆与谐波轮廓，再只改变retain/IID/procedural材料模式。旧生产位移原语另列为历史消融，不声称与新方法只差一个参数。损失积分和最终owner在纹理模式之间必须一致。修补覆盖旧裂缝与重置旧损失另做机制检查，车辙只诊断既有横断面，不强加两侧隆起。

病害内外材质统计跟随实际足迹计算：内侧5 mm为边缘，距边缘超过5 mm为内部，外侧5—15 mm为相邻正常区并排除其他病害。这些带宽仅是诊断假设。只报告遮罩内RMS、矩及相邻相关，不把遮罩造成的谱当作材料PSD。

直接表面、无噪线激光和工程噪声线激光分别保存。扫描点数、采样支持、缺测及飞点属于观测诊断；现有噪声不是设备标定，也不用于掩盖不合理几何。

公开坑槽对照先共享整帧标签和TLS参考面，再留出16个角扇区中序号模5为0的边界点，拟合其余角区的谐波。椭圆坐标已经使用整帧边界，因此必须称为同视图、已知轮廓的插值诊断。深度对照复用原16像素空间块协议。两种对照都不推导自然参数先验。

当前冻结轮廓主指标分别使用椭圆的 `r-1` 和谐波的 `r/g-1`，属于相对于各自模型边界的归一残差。它们的分母不同，不能把其百分比直接称为公共尺度的径向距离改善；还应固定系数，用 `r-1` 与 `r-g` 做公共坐标尺度敏感性检查。本轮三个视图中，一个视图在该补充尺度上略退步，因此不声称所有视图全面改善。

正式入口现可并列输出历史归一分数、公共坐标分数、原生投影径向误差、16角区贡献和边界缺测覆盖。`pothole_outline_fairness` 阶段读取冻结结果，不重做拟合；它需要额外的 `pothole_frozen_metrics` 资产，须显式选择，不改变默认阶段。壁面/坑底可选材质、原生数据导入及组合检查见[工程扩展说明](engineering-extensions.md)。

## 续跑与产物

同一命令加 `--resume`，仅当冻结输入、执行代码、依赖阶段和全部产物哈希都一致时复用。过期阶段标记为stale；依赖失效的基准不会继续报告成已完成。失败尝试保留，重跑写入新的attempt目录。改变协议应创建新的输出目录。

每次输出包括冻结清单和协议、`run_state.json`、日志、实际源码快照以及分阶段JSON/NPZ/图像。需同时阅读软件完成状态与科学结论：目前真实标定状态是 `not_calibrated`，真实域验收状态是 `not_evaluated`。

必要检查限于本轮准入/缓存、纹理选择、坑缘、实验控制及受影响重放路径；完整历史回归、训练和长条带慢测另行安排。
